# Kindride — Accessible Transport Website

All sixteen required page types are built: Home 1, Home 2, About, Services, Service Details, Blog, Blog Details, Contact, Booking, Fleet, Pricing, Login, Register, Customer Dashboard, 404, and Coming Soon / Maintenance. Review Coming Soon / Maintenance before the final audit, following the user's page-by-page process. Visual QA and live integrations remain incomplete.

Open index.html in the delivered package or serve its root using a static web server. Bootstrap 5 and both fonts are bundled. The UI uses black, white and teal; normal body text; 30px side padding; sticky navigation; theme and RTL controls; gentle motion and reduced-motion support.

See documentation/prompt-audit.md for the complete audit, remaining architecture, user overrides and verification limitations. See documentation/guide.md for installation, customization, exact image paths, integration notes and credits. verification.json records source and selected logic checks.

The business, contact details and passenger quotations are fictional content. No real booking, payment, tracking, availability, authentication or notification service is connected. Contact sending is disabled until a verified endpoint is configured. Current photos are illustrative licensed equipment images, not Kindride's fleet.
